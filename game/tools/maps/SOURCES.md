Références de téléchargement OSM utilisées pour documenter les territoires :
- Londres : Geofabrik Greater London
- Berlin : Geofabrik Berlin
- Randstad : Geofabrik Netherlands
- Bruxelles : Geofabrik Belgium
- Madrid : Geofabrik Madrid

- Varsovie : Geofabrik Poland
- Lisbonne : Geofabrik Portugal

## Extension V40.1

Les fonds des nouvelles cartes jouables utilisent le meme pipeline OpenStreetMap -> build Protomaps -> extraction PMTiles locale : New York, Ottawa, Tokyo, Vienne, Copenhague, Stockholm, Oslo, Helsinki, Athenes, Budapest, Istanbul, Sao Paulo et Sydney. Attribution de base : OpenStreetMap contributors / Protomaps.

Le catalogue affiche aussi en `A venir` : Rabat, Dubai, Dublin, Kiev, Moscou, New Delhi, Riyad, Seoul, Zagreb, Alger, Pekin, Mexico, Le Caire, Buenos Aires et Bogota. Aucun PMTiles n'est telecharge pour ces entrees tant qu'elles restent planifiees.
